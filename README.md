# 💻 2ª Lista de Exercícios em Assembly (MIPS)

Repositório destinado ao armazenamento e organização das resoluções da **2ª Lista de Exercícios de MIPS Assembly**, desenvolvidos no **MARS** (MIPS Assembler and Runtime Simulator).

---

## 🛠️ Tecnologias e Ferramentas Utilizadas

* **Linguagem:** Assembly MIPS
* **Simulador:** [MARS]

---

## 📋 Exercícios Resolvidos

| Arquivo | Descrição |
| :--- | :--- |
| `exe01.s` | **Volume de um Paralelepípedo:** Receba os valores do comprimento, largura e altura de um paralelepípedo. Calcule e mostre seu volume. |
| `exe02.s` | **Comprimento da Circunferênça:** Receba o raio de uma circunferência. Calcule e mostre o comprimento da circunferência. Considere PI = 3. |
| `exe03.s` | **Diferença Maior pelo Menor:** Receba 2 valores inteiros. Calcule e mostre o resultado da diferença do maior pelo menor valor. |
| `exe04.s` | **Média aritmética:** Receba 4 notas bimestrais de um aluno. Calcule e mostre a média aritmética. Mostre a
mensagem de acordo com a média:

a. Se a média for >= 6,0 exibir “APROVADO”;
b. Se a média for >= 3,0 ou < 6,0 exibir “EXAME”;
c. Se a média for < 3,0 exibir “RETIDO”. |
| `exe05.s` | **Somatória de Ímpares:** Recebe dois números inteiros, identifica o menor e o maior, e realiza a soma de todos os valores ímpares no intervalo. |
| `exe06.s` | **Maior e Menor Positivo:** Lê 10 inteiros positivos (solicitando novamente em caso de entradas negativas) e exibe os valores (Menor e Maior). |
